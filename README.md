## Analytics & Tracking

Visitor tracking is enabled on all pages:
- **Google Analytics 4**: Configure your GA4 Measurement ID in `docs/analytics.js`
- **Visitor Counter**: Automatic visitor badge on all pages
- **Page View Tracking**: Tracks page views, time on page, and external link clicks
- **Local Storage**: Stores last 100 page views locally for analysis

To set up Google Analytics:
1. Get your GA4 Measurement ID from [Google Analytics](https://analytics.google.com)
2. Replace `G-XXXXXXXXXX` in `docs/analytics.js` with your actual Measurement ID
